# Taking_student_attendance

Ứng dụng Web Quản Lý & Điểm Danh Võ Sinh (Student Attendance Web Application)

## Giới thiệu
Hệ thống điểm danh và quản lý võ sinh hiện đại, tối ưu cho thiết bị di động (mobile-first), dành cho Huấn luyện viên, Giáo viên chủ nhiệm và Quản trị võ đường.

## Tính năng chính
- **Điểm danh buổi tập**: Thao tác điểm danh nhanh, cảnh báo trùng/lệch ca tập.
- **Tìm kiếm võ sinh học bù**: Tìm kiếm chéo thông minh giữa các lớp trong võ đường, hỗ trợ tìm theo Tên Cuối, Họ không dấu tiếng Việt và thanh gợi ý nhanh.
- **Chụp ảnh danh sách điểm danh**: Tạo ảnh danh sách điểm danh đẹp mắt, tinh gọn để chia sẻ trực tiếp lên Zalo cho GVCN và HLV.
- **Quản lý học phí**: Theo dõi trạng thái học phí (Đã nộp / Chưa nộp / Còn nợ).
- **Phân quyền RBAC**: Phân quyền chi tiết cho Super Admin, Dojo Admin, Teacher và Coach.
- **Xóa lớp bảo mật**: Cử chỉ nhấn giữ 10 giây xác thực mật khẩu.

## Cài đặt & Khởi chạy
```bash
# Cài đặt thư viện
npm install

# Chạy môi trường phát triển
npm run dev

# Biên dịch sản phẩm
npm run build

# Chạy bản xem trước
npm run preview
```
